# 📚 Client And Server

 
> **Date:** 2026-11-26  
> **Category:** Networking 
---

## 🎯 Objective

To understand the concept of client and server, how they communicate with each other over a network, and how requests and responses work in real-world applications.

---

## 📖 Overview

A client is a device or application that requests services or information from another system.

A server is a computer or system that receives client requests, processes them, and sends back the required information or services.

Client and server communicate with each other through a network using communication protocols such as HTTP, HTTPS, FTP, and DNS.

---

## 🧠 Key Concepts

### 1. Client
A client is a device or application that sends requests to a server to access information or services.

##### Examples
- Web browsers like Chrome and Firefox.
- Mobile applications.

### 2. Server

A server is a computer or software application that listens for client requests, processes them, and provides the requested information or services.

##### Examples
- Web servers.
- Database servers.

### Client-Server Communication Process
1. The client sends a request to the server.
2. The server receives the request.
3. The server processes the request.
4. The server sends a response to the client.
5. The client displays or uses the received information.

---

## 🔍 Example

### Accessing a website

When a user opens Google Chrome and visits www.google.com:
1. Chrome acts as the client.
2. The browser sends a request to Google's web server.
3. The server receives and processes the request.
4. The server sends the website content as a response.
5. The browser displays the Google homepage.
This is an example of client-server communication using HTTP/HTTPS protocols.

## 🛡️ SOC / Security Relevance

Understanding client-server communication is important for a SOC Analyst because most network-based attacks involve communication between clients and servers.

A SOC Analyst monitors network traffic to identify suspicious communication and potential security threats.

**Security use cases:**
- Identifying unauthorized client connections to servers.
- Monitoring suspicious IP addresses and network traffic.
- Detecting unusual HTTP and HTTPS requests.
- Identifying unauthorized access attempts and suspicious server responses.

---

## 📝 Key Takeaways

- A client requests information or services, while a server provides them.
- Client-server communication follows a request-response model.
- Protocols such as HTTP, HTTPS, DNS, and FTP enable network communication.
